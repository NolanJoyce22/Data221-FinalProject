Data221 - Final Project by Eshal Tariq, Mariana Perez Perera, Evyn Brown, Nolan Joyce

We implemented 4 machine learning models using constant features, target labels and train-test split to predict student's final grades (continuous numerical value) based on their indivudual at-home environments. We each measured the following regression metrics: Root Mean-Squared Error, Mean-Squared Error, R-Squared, Mean-Absolute Error. 

1. KNN Model: Implemented by Eshal, trained a KNN model with 15 neighbors to ensure maximum performance. Additionally, made 2 visualizations to communicate findings and model performance. 
2. Linear Regression Model: Implemented by Nolan, trained a Linear Regression model and set fit_intercept to True to compute model intercepts and coefficients. Additionally, made 2 visualizations to communicate findings and model performance. 
3. Decision Tree Model: Implemented by Mariana, trained a Decision Tree model with max_depth=4, and min_samples_split=10 to ensure maximum performance. Additionally, made 4 visualizations to communicate findings, model performance and most valuable features. 
4. Neural Network Model: Implemented by Evyn, trained a Neural Network model with 4 hidden layers over 30 epochs to predict students final grades. Additionally, made 3 visualizations to communicate findings and model performance
